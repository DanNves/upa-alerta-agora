# 11 — Glossário

| Termo | Significado |
| --- | --- |
| **UPA** | Unidade de Pronto Atendimento; serviço de urgência de complexidade intermediária |
| **UPA 24h** | Unidade em funcionamento ininterrupto |
| **UPA+** | Nome do protótipo desenvolvido neste trabalho |
| **Capacidade máxima** | Número de pessoas que a unidade consegue atender simultaneamente em condições normais |
| **Ocupação atual** | Número de pessoas presentes na unidade no momento da atualização |
| **Percentual de ocupação** | Ocupação atual dividida pela capacidade máxima, em porcentagem; pode passar de 100% |
| **Nível de ocupação** | Classificação qualitativa: Baixa, Moderada, Alta ou Superlotada |
| **Superlotação** | Situação em que a ocupação supera a capacidade máxima da unidade |
| **Tempo estimado** | Estimativa de espera informada pela unidade, em minutos |
| **Tempo real de espera** | Tempo efetivamente enfrentado, informado pelo cidadão na avaliação |
| **Score de sugestão** | Valor calculado a partir de ocupação e distância; menor score indica a opção mais adequada |
| **Haversine** | Fórmula que calcula a distância em linha reta entre duas coordenadas geográficas |
| **Origem do dado** | Indicação de como a ocupação foi obtida: gestor, simulado ou estimado |
| **Campanha / Evento** | Ação de saúde temporária realizada em uma ou mais unidades |
| **Modo emergência** | Atalho para SAMU 192, Bombeiros 193 e rota para a unidade aberta mais próxima |
| **Painel do gestor** | Área restrita para atualizar ocupação, publicar campanhas e ler feedbacks |
| **MVP** | Produto mínimo viável; conjunto essencial de funcionalidades para validar a proposta |
| **Token semântico** | Variável de design (cor, sombra, raio) usada no lugar de valores fixos |
| **Feature flag** | Chave que liga ou desliga uma funcionalidade da interface |
| **Bottom sheet** | Painel deslizante que sobe a partir da base da tela |
| **SAMU** | Serviço de Atendimento Móvel de Urgência, telefone 192 |
| **SUS** | Sistema Único de Saúde |
